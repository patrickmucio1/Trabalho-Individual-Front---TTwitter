# TTwitter

O **TTwitter** é uma rede social fictícia desenvolvida como projeto individual de Front-End. O projeto possui telas de **login**, **cadastro** e **home**, com navegação entre as páginas e layout responsivo para computadores, tablets e celulares.

## Objetivo do projeto

O objetivo do projeto é praticar os conceitos básicos de desenvolvimento Front-End por meio da criação de uma interface de rede social.

O projeto busca:

- Desenvolver SEO básico para o site;
- Desenvolver telas para mobile e para telas para desktop;
- Seguir fielmente as propriedades do protótipo;
- Legibilidade do projeto;

## Tecnologias utilizadas

- **HTML5:** utilizado para estruturar o conteúdo e os elementos das páginas;
- **CSS3:** utilizado para estilização, posicionamento e responsividade;
- **Visual Studio Code:** utilizado para escrever e organizar o código;
- **Git e GitHub:** utilizados para versionamento e publicação do projeto.

> O projeto foi desenvolvido apenas com HTML e CSS. Não possui banco de dados, autenticação real ou JavaScript.

## Exemplos de uso

### Acessar a página inicial

1. Abra o arquivo `index.html`;
2. Preencha o campo **Email** com um endereço de e-mail válido;
3. Preencha o campo **Senha**;
4. Clique no botão **Entrar**;
5. O usuário será direcionado para a página `home.html`.

Os campos de email e senha são obrigatórios. Caso estejam vazios ou o email esteja em um formato inválido, o navegador impedirá o envio do formulário.

### Acessar a tela de cadastro

1. Na tela de login, clique em **Registrar**;
2. Preencha os campos solicitados;
3. Marque a opção de concordância com os termos;
4. Clique em **Cadastrar**.

### Voltar para o login

Na tela de cadastro, clique em **Fazer Login** para retornar à página `index.html`.

## Responsividade

A interface foi desenvolvida para se adaptar a diferentes tamanhos de tela:

- Desktop;
- Tablet;
- Celular.

Na versão mobile, o menu de navegação é exibido na parte inferior da tela.
